## Présentation

L'objectif était de développer un script python permettant la création de Qr Code. Pour cela, j'ai utilisé la bibliothèque 'qr code'. 

## Fonctionnalités

* Créer des QR Codes à partir de liens.

## Manuel d'utilisations 

Pour l'utiliser, il faut installer les bibliothèques nécessaires grâce à cette commande : 

```bash
pip install "qrcode[pil]" 
```
